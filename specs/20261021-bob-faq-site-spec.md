## 背景・目的

`qa.md` に英語のFAQ（4カテゴリ・17問）がある。これを日本語に翻訳し、バックエンドなしで閲覧・検索できる静的FAQサイトとして公開できる形にする。

## 現在の挙動

* リポジトリには英語の `qa.md` のみが存在し、閲覧用のサイトはない。

## 期待する挙動

* `index.html` をブラウザで開くだけで、日本語のFAQを閲覧・検索・カテゴリ絞り込みできる。

## 対象範囲・対象外

### 対象範囲

* 静的サイト（HTML / CSS / JavaScript）の新規作成
* `qa.md` の全17問の日本語翻訳（JSデータとして保持）
* 検索、カテゴリ絞り込み、アコーディオン開閉

### 対象外

* バックエンド、外部ライブラリ、CDN、ビルド工程
* 多言語切替、お気に入り等の追加機能
* `qa.md` 自体の変更

## 主な仕様

* FAQデータは `faq-data.js` に保持し、`app.js` が描画する。
* カテゴリは「一般」「使い方」「高度な機能」「トラブルシューティング」（`qa.md` の `##` 見出しに対応）。
* カテゴリ絞り込み: 「すべて」＋上記4カテゴリのボタン。選択中は1つのみ。
* キーワード検索: 質問文・回答文を対象に、入力ごとにリアルタイムで部分一致（大文字小文字は区別しない）。カテゴリ絞り込みとAND条件で併用。
* アコーディオン: 質問クリックで回答を開閉。複数同時に開ける。
* 回答は段落、箇条書き、太字、インラインコード（`` ` ``）を表現できること。
* 表示件数（「N件の質問」）を一覧上部に表示する。
* 絞り込み結果が0件の場合は「該当する質問がありません」を表示する。

## 制約・非機能要件

* HTML / CSS / JavaScript のみ。`file://` で直接開いても動作する（ES Modules・fetch を使わず、通常の `<script>` で読み込む）。
* レスポンシブ対応（スマホ〜PC）。
* アクセシビリティ: 各質問はボタン要素、`aria-expanded` / `aria-controls` を設定、キーボード（Tab / Enter / Space）で操作可能、フォーカス表示あり。
* XSSを避けるため、回答は `textContent` ベースのDOM生成で描画する（`innerHTML` に文字列を直接流し込まない）。
* `<html lang="ja">`。

* 検索入力で即時絞り込み。カテゴリボタン押下で即時絞り込み。
* ページ遷移・再読み込みなし。

### 操作・画面遷移（追記）

* Bob画像クリック: `https://www.ibm.com/products/bob` を新しいタブで開く。
* テーマ切替ボタンクリック: ダーク/ライトを即座に切り替える。ボタンのラベルも切り替わる。

### 表示状態

* 初期表示: 全17件表示、すべて閉じた状態、カテゴリは「すべて」。OS設定がダークの場合はダークテーマで表示。
* 絞り込み後: 条件に一致する項目のみ表示、件数更新
* 空状態: 「該当する質問がありません」を表示、件数は「0件の質問」
* 読み込み中・エラー: 対象外（データはローカルJSで同期読み込みのため）

### 入力・バリデーション

* 検索ボックスは自由入力、文字数制限なし。前後の空白は無視する。

### デザイン要件

* 白基調・グラデーションアクセント（`#0f62fe → #a56eff`）のシンプルなデザイン。システムの日本語フォント（`"Hiragino Sans", "Yu Gothic UI", "Meiryo", sans-serif` 等）。
* コンテンツ幅は最大約800pxで中央寄せ。小画面では余白と文字サイズを調整し、カテゴリボタンは折り返す。
* アクセシビリティ: 文字と背景のコントラスト比を十分に確保する。`prefers-reduced-motion` ではアニメーションを無効化。ダークテーマでもコントラスト比を確保する。

## リスク・懸念点

* 翻訳は自動で行うため、訳語は本仕様書のレビューで確認する。
