## 実装手順（v2）

### 手順1: `index.html` の更新

* ヘッダー内の `.container` に以下を追加・変更する:
  1. タイトルの左に Bob画像リンクを追加
     ```html
     <a href="https://www.ibm.com/products/bob" target="_blank" rel="noopener noreferrer" class="header-logo">
       <img src="bob.svg" alt="Bob" height="48">
     </a>
     ```
  2. ヘッダー右端にテーマ切替ボタンを追加
     ```html
     <button type="button" id="theme-toggle" class="theme-toggle" aria-label="ダークテーマに切り替え">🌙</button>
     ```
  3. ヘッダーの `.container` をフレックスレイアウトに変更し、画像・テキスト・ボタンを横並びにする

### 手順2: `style.css` の更新

1. **ヘッダー背景をグラデーションに変更**
   * `.site-header` の `background: var(--accent)` を `background: linear-gradient(to right, #0f62fe, #a56eff)` に変更
2. **ヘッダーレイアウト調整**
   * `.site-header .container` をフレックスレイアウト化（画像左・テキスト中央寄り・ボタン右）
   * `.header-logo img` のサイズ・余白を設定
3. **テーマ切替ボタンのスタイル**
   * 背景なし・ボーダーなし、白アイコン、カーソルポインター
4. **ダークテーマのCSS変数定義**
   * `:root` のライト変数に加え、`[data-theme="dark"]` セレクタでダーク変数を上書き
   * `@media (prefers-color-scheme: dark)` でも同様の変数を適用（`[data-theme="light"]` 指定時は上書きしない）

### 手順3: `app.js` の更新

テーマ切替ロジックを `app.js` の末尾（`IIFE` 内）に追加する:

1. `<html>` 要素の `data-theme` 属性を操作する `applyTheme(theme)` 関数を定義
2. 初期テーマ判定: `data-theme` 属性がなければ `prefers-color-scheme` を参照して設定
3. `#theme-toggle` ボタンのクリックイベントでテーマを反転し、ボタンラベルを更新
4. ボタンラベルは `🌙`（ライト時・ダークへ切替）と `☀️`（ダーク時・ライトへ切替）

### 手順4: 動作確認

ブラウザで `index.html` を開いて確認する。

## GUI実装

* 対象コンポーネント: `index.html` の静的領域と、`app.js` が動的生成するカテゴリボタン群・アコーディオン項目・空状態
* スタイル: `style.css` に集約。外部フォント・CDNは使用しない
* 状態管理: `app.js` 内の単純な変数（選択カテゴリ、検索語、開いている項目ID集合、テーマ）。変更のたびに一覧を再描画
* 画面遷移: なし
* レスポンシブ対応: `max-width` ＋ `@media (max-width: 600px)` で余白・文字サイズ調整、カテゴリボタンは `flex-wrap` で折り返し
* テーマ管理: `<html data-theme>` 属性で CSS 変数を切り替え。OS設定を `window.matchMedia` で検出
